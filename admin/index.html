第一步：连接 GitHub

粘贴一次令牌即可，浏览器会记住。令牌只授予本仓库的文件读写权限。

还没有令牌？点这里生成（约 1 分钟）：
1. 打开 github.com/settings/personal-access-tokens/new
2. Token name 填「网站后台」；Expiration 选 No expiration 或 1 年
3. Repository access 选 Only select repositories → 选 quanyudalian
4. Permissions → Repository permissions → Contents 设为 Read and write（其余不动）
5. 点 Generate token，复制 github_pat_ 开头的字符串粘贴到上面

第二步：修改网站内容

改完点底部「保存并上线」，约 1 分钟后官网自动更新（Cloudflare 重新部署）。

产品价格

填数字即可带货币符号，如「¥3,280」。
